# Animed — GLOBAL HEALTH BRIDGE

海外でも、日本語で医療につながる。渡航前チェック・薬・英文書類・オンライン相談・現地連携・緊急対応を一つにする利用者向けアプリ（PWA）です。

## 構成
- `index.html` — 利用者アプリ本体（単一HTML / PWA）
- `manifest.json`, `icon-192.png`, `icon-512.png` — PWA設定とアイコン
- `.nojekyll` — GitHub Pages のJekyll処理を無効化

## 実装済み機能（MVP）
- ホーム（現在の渡航・リスク要約・相談サマリ）
- 渡航登録 → 問診 → 自動判定（国×薬×疾患のリスク分類と必要書類提案）
- 薬の管理 / 渡航書類（状態管理）
- 日程調整（医師・薬剤師・通訳の空き枠マッチング ○△×）
- オンライン通話 → 相談サマリと書類状態の自動更新
- 緊急サポート（渡航国の救急番号・現在地取得・日本語サポート導線）

## 次フェーズ
医師・薬剤師の実通話、書類PDF生成、国別ルールDBの管理画面、団体（学校・企業）管理、請求・成果報酬、バックエンド（D1 / Worker）。

## 注意
本アプリの判定は支援範囲の目安であり、診断・治療方針を確定するものではありません。薬剤の持込可否は渡航国・成分・数量・滞在期間・現地法令により異なり、医師の書類は説明資料であって持込を保証しません。重い症状は現地の救急を最優先してください。
